# قالب التقرير الأسبوعي للمهام (PowerPoint، A4 عمودي، عربي)

قالب من صفحة واحدة يرفعه الموظف إلى مديره أسبوعيًا. مستوحى من الهوية البصرية لسدايا
(كحلي داكن، تدرّج تركوازي/أخضر، زخرفة شبكية) دون استخدام شعارها، ومعدّ لجهة أخرى تضع شعارها واسمها.

## الملفات

| الملف | الغرض |
|---|---|
| `out/التقرير_الأسبوعي_قالب.pptx` | **القالب** الذي تعمل عليه: الشريحة 1 نموذج فارغ بحقول إرشادية، والشريحة الأخيرة مخفية فيها دليل الاستخدام. |
| `out/التقرير_الأسبوعي_مثال.pptx` و `out/التقرير_الأسبوعي_مثال.pdf` | مثال معبّأ ببيانات تجريبية يوضح الشكل النهائي. |
| `out/preview_example.png` | معاينة سريعة للمثال. |
| `fonts/` | خط IBM Plex Sans Arabic (ترخيص OFL مفتوح) — ثبّته مرة واحدة قبل فتح القالب. |
| `build_template.py` | المولّد (Python + python-pptx). يعيد بناء القالب والمثال، وفيه كل الألوان والنصوص والمقاسات. |
| `render.sh` | تحويل PPTX إلى PDF وصور للمراجعة (LibreOffice). |

## الاستخدام في 60 ثانية

1. **ثبّت الخط**: افتح مجلد `fonts`، انقر كل ملف نقرًا مزدوجًا ثم «تثبيت» (لا يحتاج صلاحيات مسؤول في ويندوز 10/11).
2. **افتح القالب** واكتب داخل الحقول ذات النص الإرشادي الرمادي. يختفي النص الإرشادي فور الكتابة، وما تتركه فارغًا لا يُطبع.
3. **الشعار**: انقر أيقونة الصورة أعلى اليمين وأدرج شعار جهتك مرة واحدة.
4. **المهام الجارية**: جدول؛ Tab في آخر خلية يضيف صفًا، وزر الفأرة الأيمن ← حذف ← الصفوف لإزالة صف.
5. **الإخراج**: ملف ← تصدير ← إنشاء PDF ← خيارات ← «الشريحة الحالية». الشريحة المخفية لا تُصدَّر.
6. **الأسبوع التالي**: حدّد شريحة الأسبوع السابق واضغط Ctrl+D. تظهر نسخة جديدة وعليها «تقرير رقم 2» تلقائيًا، وتبقى التقارير السابقة أرشيفًا في الملف نفسه.

## كيف يعمل العداد؟

«تقرير رقم N» حقل مرتبط برقم الشريحة. كل تكرار للشريحة يزيد الرقم. الشريحة المخفية (الدليل) في آخر الملف
فلا تؤثر على الترقيم. إن حذفت تقارير قديمة، اضبط «ترقيم الشرائح من» في: تصميم ← حجم الشريحة ← حجم شريحة مخصص.

## لماذا صُمّم هكذا؟ (قرارات التصميم)

- **A4 عمودي بأبعاد دقيقة 210×297 مم**: يُقرأ على الهاتف بالتمرير الطبيعي، ويُطبع دون قص، وملف PDF يخرج بمقاس A4 قياسي.
- **ترتيب الأقسام يتبع ما يريده المدير**: خلاصة ثم منجز ثم جارٍ ثم قادم ثم قرار مطلوب ثم تحديات. أثر الموقع (serial position): أهم شيئين في البداية والنهاية.
- **ثلاثة أرقام كبيرة** (منجز/جارٍ/قادم) تمنح إحساسًا بحجم الأسبوع قبل القراءة، وتُلتقط بالنظرة الأولى حتى على شاشة الهاتف.
- **صندوق «قرار مطلوب»** مميّز بلون واحد مختلف (أثر فون ريستورف): الشيء الوحيد الذي يحتاج فعلًا من المدير لا يضيع.
- **«التحديات» قسم هادئ**: رمادي خافت وخط أصغر، فيبقى موجودًا وقابلًا للعثور عليه دون أن يصبغ التقرير بلون سلبي.
- **تسلسل هرمي بالحجم والوزن لا بالزخرفة**: عنوان 20pt، عناوين أقسام 12.5pt عريضة، متن 12pt، جدول 11pt، تسميات 7.5–9pt. بدون خطوط زخرفية تحت العناوين.
- **تباعد أسطر 1.28–1.32** يناسب الحروف العربية الصاعدة والنازلة والتشكيل.
- **جدول بخطوط أفقية فقط** وصف عنوان بلون فاتح: أسهل مسحًا بصريًا من الشبكة الكاملة.
- **تباين عالٍ** للنص الأساسي (كحلي/أسود مزرق على أبيض)، ولون خافت للنص الثانوي فقط.
- **التصغير التلقائي عند الامتلاء** (Shrink text on overflow) مفعّل في كل الحقول: إن كتبت أكثر من المتوقع ينكمش الخط بدل أن يخرج النص عن الصفحة.

## التخصيص

- الألوان والنصوص والمقاسات في أعلى `build_template.py` (`PALETTE`، `TXT`).
- لتغيير العناوين الثابتة من داخل PowerPoint: عرض ← الشريحة الرئيسية ← تخطيط «التقرير الأسبوعي».
- إعادة البناء:

```bash
python3 build_template.py --out out/template.pptx
python3 build_template.py --out out/example.pptx --example
./render.sh out/example.pptx ex
```

المتطلبات: Python 3 مع `python-pptx` و `lxml` و `Pillow`؛ وللمعاينة LibreOffice و `pdftoppm`.
